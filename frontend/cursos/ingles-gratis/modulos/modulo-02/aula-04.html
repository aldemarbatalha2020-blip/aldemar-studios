There Is and There Are

Aprenda a dizer que algo existe ou está presente em determinado lugar.

📚 1. Conteúdo

Singular

There is = Há / Existe / Tem

There is a table in the kitchen.

Há uma mesa na cozinha.

Plural

There are = Há / Existem / Tem

There are three chairs in the room.

Há três cadeiras no quarto.

Forma negativa

There isn't a television.

There aren't any books.

Perguntas

Is there a sofa?

Are there two bedrooms?

🎙️ 2. Explicação do Professor Aldemar

Use there is quando estamos falando de uma coisa no singular. Use there are quando estamos falando de duas ou mais coisas. Essa diferença é muito importante para descrever casas, salas e lugares.

💡 Dica do Professor: Leia os exemplos lentamente, compreenda o significado e depois tente criar frases próprias.

📖 3. Atividade de Leitura

My bedroom is simple.

There is a bed next to the wall.

There is a desk near the window.

There are two chairs in the room.

There are some books on the desk.

1. How many chairs are there in the bedroom?

2. Which sentence is correct?

✍️ 4. Atividade de Escrita

Escreva 4 frases: duas usando There is e duas usando There are.

🗣️ 5. Atividade de Pronúncia

Leia cada frase em Inglês em voz alta. Depois clique no botão para ouvir a pronúncia.



🎯 Desafio da Aula

Descreva um cômodo imaginário usando pelo menos duas frases com There is e duas com There are.
