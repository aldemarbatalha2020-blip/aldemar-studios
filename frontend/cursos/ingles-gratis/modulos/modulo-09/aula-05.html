Módulo 09 — Aula 05: Verbos com -ing

Aprenda regras básicas para formar o gerúndio em inglês.

Regras

play → playing

read → reading

work → working

write → writing

make → making

run → running

Atenção

Alguns verbos sofrem alterações na escrita antes de receber -ing.

Prática

Transforme: study, dance, run, swim, make.
