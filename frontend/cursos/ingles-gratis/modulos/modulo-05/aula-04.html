There is / There are — Negative — Frases negativas

← Voltar para os módulos

📚 1. Forma negativa

Para dizer que algo não existe ou não está presente, usamos:

There isn't = não há / não existe (singular)
There aren't = não há / não existem (plural)

There isn't

There isn't a bank here.

Não há um banco aqui.

There isn't a hospital near my house.

Não há um hospital perto da minha casa.

There aren't

There aren't any restaurants here.

Não há restaurantes aqui.

There aren't two schools in my neighborhood.

Não existem duas escolas no meu bairro.

Atividade

Transforme em negativa:

1. There is a park here.

2. There are two banks.

3. There is a supermarket near my house.

4. There are three restaurants.
