There is / There are — Affirmative — Frases afirmativas

← Voltar para os módulos

📚 1. Frases afirmativas

Agora vamos construir frases completas usando There is e There are.

There is a school in my city.
Há uma escola na minha cidade.

There are many shops here.
Há muitas lojas aqui.

Estrutura

There is + singular + complemento.

There is a bank near my house.

There are + plural + complemento.

There are two parks in my neighborhood.

Vocabulário

near = perto

city = cidade

neighborhood = bairro

house = casa

shop = loja

Atividade

Crie 3 frases usando There is.

Crie 3 frases usando There are.
