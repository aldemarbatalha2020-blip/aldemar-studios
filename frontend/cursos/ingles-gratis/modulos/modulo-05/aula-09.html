🔄 1. Revisão geral

Nesta aula vamos revisar os principais conteúdos estudados no Módulo 05.

Vocabulário

school — escola

hospital — hospital

bank — banco

supermarket — supermercado

restaurant — restaurante

park — parque

library — biblioteca

pharmacy — farmácia

There is / There are

There is a school.
There are two schools.

There isn't a bank.
There aren't any banks.

Preposições

near — perto

next to — ao lado

behind — atrás

in front of — em frente

between — entre

Desafio

Escreva um pequeno texto sobre seu bairro usando:

• There is

• There are

• There isn't

• There aren't

• pelo menos 3 lugares

• pelo menos 2 preposições

✅ Conclusão da Aula

Revise o conteúdo desta aula antes de avançar. A aprendizagem do módulo acontece de forma progressiva, por isso é importante compreender cada etapa.
