📖 1. O que são Articles?

Em inglês, os Articles são palavras utilizadas antes de substantivos.

Em português, usamos palavras como o, a, um, uma. Em inglês, os principais artigos são:

A → um / uma

AN → um / uma

THE → o / a / os / as

🔵 2. O artigo A

Usamos A antes de palavras que começam com som de consoante.

A + palavra

a book → um livro
a car → um carro
a house → uma casa
a teacher → um professor
a student → um estudante

Exemplos em frases

I have a book.
Eu tenho um livro.

She is a teacher.
Ela é professora.

He has a car.
Ele tem um carro.

🟢 3. O artigo AN

Usamos AN antes de palavras que começam com som de vogal.

AN + palavra

an apple → uma maçã
an orange → uma laranja
an egg → um ovo
an elephant → um elefante
an animal → um animal

Exemplos em frases

I have an apple.
Eu tenho uma maçã.

She eats an orange.
Ela come uma laranja.

It is an animal.
É um animal.

⚠️ Atenção!

O mais importante é observar o som inicial da palavra.

O artigo AN é utilizado quando a palavra começa com som de vogal.

🔎 4. A ou AN?

Artigo Palavra Tradução
A a book um livro
A a car um carro
A a house uma casa
AN an apple uma maçã
AN an egg um ovo
AN an elephant um elefante

🟣 5. O artigo THE

O artigo THE pode significar:

THE = o / a / os / as

Diferentemente de A e AN, usamos THE quando estamos falando de algo específico ou conhecido.

the book
o livro

the house
a casa

the students
os estudantes

the teacher
o professor / a professora

📊 6. A, AN e THE

Artigo Uso Exemplo Tradução
A Som de consoante a dog um cachorro
AN Som de vogal an apple uma maçã
THE Algo específico the dog o cachorro

🗣️ 8. Diálogo

Anna: What is this?

John: It is a book.

Anna: Is it an English book?

John: Yes, it is.

Anna: Is the book new?

John: Yes. The book is new.

Tradução

Anna: O que é isso?
John: É um livro.
Anna: É um livro de inglês?
John: Sim.
Anna: O livro é novo?
John: Sim. O livro é novo.

📌 11. Resumo da Aula

A → usado antes de palavras com som de consoante.

a book

AN → usado antes de palavras com som de vogal.

an apple

THE → usado para algo específico ou conhecido.

the book

Lembre-se: A, AN e THE aparecem constantemente nas frases em inglês.
