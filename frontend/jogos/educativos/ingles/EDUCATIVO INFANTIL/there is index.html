🌈 THERE IS & THERE ARE 🌈

Vamos aprender inglês brincando! 🚀📚

🏠✨

O que significa?

Quando queremos dizer que tem ou que existe alguma coisa, podemos usar:

🟢 THERE IS
1 coisa
🔵 THERE ARE
2 ou mais coisas

🧠 A regra é muito fácil!

THERE IS

☝️🐱

UMA COISA

There is a cat. 🐱 Tem um gato.
There is a book. 📖 Tem um livro.

THERE ARE

🐱🐱🐱

DUAS OU MAIS COISAS

There are two cats. 🐱🐱 Tem dois gatos.
There are many apples. 🍎🍎🍎 Tem muitas maçãs.

✨ A REGRA MÁGICA ✨

☝️ ONE
THERE IS
✌️ TWO
THERE ARE
🌟 MANY
THERE ARE

🧩 Como formar a frase?

☝️ UMA COISA

THERE IS
+
A / AN
+
COISA
THERE IS + A + DOG
🐶
There is a dog.

✌️ DUAS OU MAIS COISAS

THERE ARE
+
NUMBER
+
COISAS
THERE ARE + TWO + CATS
🐱 🐱
There are two cats.
